How far to trust it

Code checks every claim. An entity type or date is shown as fact only when its quote is on the cited page of RBI's PDF and actually supports it. Anything else is marked check, so you read that part yourself.

It was tested on 55 RBI notifications it had never seen, in two release runs, against answer keys written by hand before any prompt existed. The bar was strict: no applicable notification missed.

  • Release run 1 (35 notifications): missed 2 of 59 notification and entity-type pairs, 95% precision, 0 of 105 dates wrong. Failed.
  • Release run 2 (20 new notifications): missed 1 of 51 pairs, 100% precision, 1 of 60 dates wrong. Failed.

Two of the three misses were right answers from the model that my own check threw away. This page now shows those as may apply: check instead of hiding them. Re-scored on the same answers, that leaves 1 miss in 110 pairs. That figure was measured after the fact, so it isn't a pass. Every run, with its errors.
